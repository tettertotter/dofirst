# UI Patterns to Mirror (Familiar to Due users)

- **Quick Add first**: launch opens input; microphone button is primary; one-tap submit.
- **Snooze chips**: +10m, +1h, Tonight, Tomorrow AM; show as primary actions on cards and notifications.
- **Snooze Wheel**: compact time picker for custom time; keep it single-screen, no multi-step forms.
- **Calm list**: simple, legible, large tap targets; no projects; filters by tag and state.
- **Haptics**: success, accept, decline micro-haptics; no flashy animations.
- **Accessibility**: dynamic type, VoiceOver/TalkBack labels, contrast AA+.
