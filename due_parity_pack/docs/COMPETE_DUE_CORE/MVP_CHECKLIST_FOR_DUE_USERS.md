# MVP Checklist — What a Due user expects

- [ ] Quick Add opens on launch; text or dictation; submit with only a title.
- [ ] Auto-snooze repeats until acted on; no silent failures.
- [ ] One-tap defer: +10m / +1h / Tonight / Tomorrow AM.
- [ ] Daily/Weekdays/Weekly/Monthly(Date)/Yearly recurrences.
- [ ] Today view shows accepted items and pending suggestions by person with remaining quota.
- [ ] Quiet hours respected; catch-up alert after quiet hours.
- [ ] Cross-device sync works within seconds on iOS/Android/Web.
- [ ] Email-to-task creates tasks and parses `#tags`, `!1..5`, `@today/@YYYY-MM-DD`.
