# Due → TodayPool Core Parity Pack (Supplement)
Updated: 2025-11-01 17:03 UTC

This folder helps us ship an MVP that **feels at home for a Due user** while offering a better core: faster capture, respectful but persistent nags, effortless reschedule, cross‑platform, and trusted‑people collaboration.

**Scope**: No watch app, no timer hub, no bells and whistles. **Only core reminders** done extremely well, with Today proposals and quotas.

**How to use**
1. Read `CORE_PARITY_MATRIX.md` to understand parity vs. delight.
2. Implement the algorithm in `code/nagging.ts` and wire notification actions.
3. Mirror the micro‑interactions in `UI_PATTERNS_TO_MIRROR.md`.
4. Follow `IMPLEMENTATION_GUIDE_IOS_ANDROID_WEB.md` for reliable local notifications.
5. Verify with `acceptance/ACCEPTANCE_TESTS.md` and `MVP_CHECKLIST_FOR_DUE_USERS.md`.
6. Use `PROMPT_FOR_CLAUDE.txt` as your initial instruction in VS Code.
