# Core Parity Matrix (Due vs TodayPool)

Legend: ✅ MVP | 🔜 Near-term (post-MVP) | ⏭️ Backlog

| Capability | Why Due users care | Due (reference) | TodayPool plan | Status |
|---|---|---|---|---|
| **Lightning‑fast add** with natural date parsing | Capture without friction | Due highlights quick set + natural parsing | Quick Add opens on launch; parser supports "today 5pm", "in 10 min" | ✅ |
| **Auto‑snooze (persistent nagging)** | You can’t forget; reminders re‑alert until acted on | Auto Snooze every 1/5/10/15/30/60 min | Nagging 2.0: repeat at smart cadence; action buttons: Done / +10m / +1h / Tomorrow AM | ✅ |
| **Quick postpone** | One‑tap defer at common intervals | Clever time picker & quick postpone | Chips: +10m, +1h, Tonight, Tomorrow AM, Custom; long‑press to set defaults | ✅ |
| **Recurring reminders (core)** | Repeating chores/meds | Powerful recurring patterns | MVP: daily, weekdays, weekly, monthly (date), yearly; 🔜 nth-weekday | ✅ / 🔜 |
| **Simple list UI** | Calm, no projects | Minimal lists + Logbook | Pool + Today + Inbox; no projects; log on done | ✅ |
| **Reliable notifications** | Trust that it fires | iOS local + Watch taps | Local notifications with fallbacks; quiet hours; badge counts | ✅ |
| **Sync** | Same reminders everywhere | iCloud/Dropbox | Supabase realtime across iOS/Android/Web | ✅ |
| **Timers** | Kitchen timers | Countdown timers | Not core to this product | ⏭️ |
| **Siri Shortcuts / URL scheme** | Fast capture via automations | Shortcuts + URL scheme | Deep links + App Intents later | 🔜 |
| **Apple Watch** | Wrist nags | watchOS | Not MVP | ⏭️ |
| **Android & Web** | Cross‑platform gap | Not offered | Full parity on Android/Web | ✅ |
| **Assigning to others** | Share load | Not offered | Today proposals with per‑person quotas | ✅ |
| **Email‑to‑task** | Inbox capture | Not offered | Mailgun inbound | ✅ |

References: Due’s auto-snooze and quickness are core to its appeal; see `RESEARCH_SOURCES.md` for links.
